Safety boundary

The archive is evidence, not trusted application code

Historical uploads open only as clearly labeled external provenance links. They are never executed inside this site. The three original clean-room restorations can be previewed on demand in a unique-origin iframe with scripts and downloads only—no same-origin access, forms, popups, camera, microphone, geolocation, or network credentials.

Method and provenance

The source audit used the public, unauthenticated WordPress REST API and passive HTTP retrieval only. Numbered filename variants were grouped, SHA-256 compared, and then curated into product families. The checked-in evidence snapshot has SHA-256 {{ museum.source.audit_sha256 }}.

The museum data, public API, and RAPP Vision brief feed are regenerated by scripts/build_lost_apps_museum.py; --check proves that the committed outputs still match the verified evidence.
