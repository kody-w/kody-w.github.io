# kody-w: the home repo

Start here. This repo is the home for everything public under github.com/kody-w: it is the website
(https://kody-w.github.io) and the map an AI uses to find the right repo. Each repo keeps its own code, history and
issues; this file points at them.

- Working on this website itself? Read CLAUDE.md in this folder.
- Looking for a project? Open the one area file below that fits, then clone only the repo you need.
- New to RAPP? Start with repos/rapp-core.md: the kernel, the standard and the catalog.
- The same list as data: api/home.json. The site's reading list for AIs: llms.txt.
