Sources & capability state · Quest v1.1.0 · Reviewed 18 September 2026

This is a dated training snapshot, not a release or live-provider certification. Sources: AI Brainstem Desktop 0.1.0 onboarding; the final AI Brainstem runtime documentation for identity, agent portability, semantic UI autopilot, private work, backups, and the Copilot SDK 1.0.13 capability-state matrix; and the protected Work Organization and semantic UI resources. Documentation is pinned to the exact reviewed revisions below.

  • Desktop onboarding source, revision b2d857e. This snapshot targets Apple silicon Macs. A compatible, trusted distributable is required; the existence of a source repository is not an installer guarantee.
  • Brainstem source, final revision f8f2b77. The agent, workspace, portability, and SDK behavior taught here is documented and offline-tested at this revision; the app you have installed may be older until it is updated.
  • Gauntlet Loop upstream, revision 9b1975a. Its unmodified skill and license are pinned under CC BY 4.0 and wrapped by Brainstem as a prompt-only generated agent.
  • agent.py is Brainstem’s only first-class executable capability. Normal local skill-name/SKILL.md directories remain byte-preserved, ecosystem-compatible resources. Brainstem exposes deterministic generated agents that reference those folders; it does not present plain skills as peer tools.
  • Capability cards separate Supported, On or Off, Configured or Not configured, Needs approval, Provider dependent, SDK limitation, and last actual evidence. On with zero configured roles, routines, active tasks, caps, or Apps is valid. This quest does not claim every provider behavior was observed live.
  • Safely supportable defaults include the bounded Canvas/Results path, verified static MCP App rendering after positive negotiation, isolated runtime/store/cache state, owned Stop, bounded attached tasks, create-and-resume file tracking, exact-approval journaled sandbox rewind, and local content-free diagnostics. Exact SDK limitations remain for selective continue_pending_work, unrestricted detach, enforceably local native memory, native telemetry locality, and interactive MCP Apps.
  • SDK-neutral mapping and immutable successor generations preserve workspace authority; they are not a promise that every execution adapter or migration is available. Lawful restore or fresh hatch must not be simulated.

When a required capability is missing, retain the proposed work and its blocker, use “Gate recorded,” and preview dependent lessons without inventing twins, evidence, or results.
